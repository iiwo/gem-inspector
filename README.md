# Gem Inspector - Ruby Dependency Analysis Tool

This repository contains an exercise and comparison between different AI coding assistants. Each branch demonstrates the implementation of a Ruby gem called "gem-inspector" following identical [instructions](/instructions.md).

## Project Overview

Gem Inspector is a Ruby gem that analyzes Gemfile.lock files to:
- Extract dependency information (names and locked versions)
- Query the RubyGems.org API for version metadata
- Compare locked versions against the latest available versions
- Evaluate maintenance status based on release dates
- Generate detailed CSV reports about your project dependencies

## AI Assistant Implementations

This project showcases how different AI coding assistants approach the same development task:

- [Cursor](https://github.com/iiwo/gem-inspector/tree/cursor) - Implementation using Cursor AI
- [GitHub Copilot (Agents)](https://github.com/iiwo/gem-inspector/tree/copilot) - Implementation using GitHub Copilot
- [Augment Code](https://github.com/iiwo/gem-inspector/tree/augment_code) - Implementation using Augment Code
